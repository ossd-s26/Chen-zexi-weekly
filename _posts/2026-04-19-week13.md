## This Week

Short update this week. Most of my time went into a new contribution to [Nanobot](https://github.com/HKUDS/nanobot): [PR #3173](https://github.com/HKUDS/nanobot/pull/3173), which adds OpenTelemetry-based observability for LLM calls and tool executions.

## The Contribution

Nanobot had no built-in way to trace what happens during a message — which LLM calls fired, which tools ran, how long each step took. There were a few open issues asking for Langfuse and LangSmith support, and the obvious-but-wrong approach would be to integrate each backend's SDK directly. Instead I wired up OpenTelemetry and emitted standard OTLP traces, which both Langfuse and LangSmith now ingest natively. One wire format, any OTLP-compatible backend works for free (Jaeger, Honeycomb, Datadog, whatever).

## Connecting to Last Week

Funny timing with last week's discussion on open source business models. The PR I shipped this week plugs into exactly the pattern we talked about: LangChain gave away the framework and monetizes through LangSmith; Langfuse is open source but sells the hosted backend. Both leaned into OTel as an open standard because lowering adoption friction grows the pie. The revenue comes from running the backend, not from owning the instrumentation.
